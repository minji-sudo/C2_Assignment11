# 과제 11: 삽입 정렬과 쉘 정렬의 성능 비교

무작위 정수 데이터에 삽입 정렬, 쉘 정렬(기본 간격), 쉘 정렬(Knuth 간격) 을 적용하고, 데이터 값끼리 비교한 횟수를 측정해서 성능을 비교했다.


## 1. 실행 방법

- 난수 시드를 `12345`로 고정해서 같은 결과가 나오도록 했다.
- 데이터 크기 n = 1,000 / 2,000 / 4,000 / 8,000 / 16,000 / 20,000 에 대해 실험했다.
- 각 크기마다 같은 원본 데이터를 복사해서 세 정렬에 똑같이 넣었다.
- 정렬이 끝난 뒤 오름차순이 맞는지 확인했다.

## 2. 구현 방법

### 비교 횟수 세는 기준
- 데이터 값끼리 비교하는 `a[j] > key` 연산을 할 때마다 1회로 셌다. (결과가 참이든 거짓이든 똑같이 1회)
- `for`, `while`의 인덱스 검사(`j >= 0` 등)는 세지 않았다.
- 원본 데이터 생성과 배열 복사는 세지 않았다.

### 세 가지 정렬

| 정렬 | 간격(gap) |
|---|---|
| 삽입 정렬 | 1칸 간격 (바로 앞 원소와 비교) |
| 쉘 정렬 (기본) | `n/2, n/4, n/8, ..., 1` |
| 쉘 정렬 (Knuth) | `h = 3h + 1` 수열(1, 4, 13, 40, 121, ...)에서 **n보다 작은 가장 큰 값**부터 거꾸로 `..., 13, 4, 1` |

쉘 정렬은 `gap_insertion(a, n, gap)` 함수 하나로 "gap칸 떨어진 원소끼리 삽입 정렬"을 하게 만들었고, 간격만 바꿔서 두 가지 쉘 정렬을 구현했다. gap이 1이면 일반 삽입 정렬과 똑같이 동작한다.



## 3. 실험 결과

| 데이터 크기 (n) | 삽입 정렬 | 쉘 정렬 (기본) | 쉘 정렬 (Knuth) |
|---:|---:|---:|---:|
| 1,000 | 256,417 | 16,263 | 13,885 |
| 2,000 | 1,029,853 | 35,739 | 32,355 |
| 4,000 | 3,988,578 | 83,567 | 76,412 |
| 8,000 | 16,102,278 | 201,908 | 184,562 |
| 16,000 | 63,806,883 | 491,819 | 431,732 |
| 20,000 | 100,641,654 | 641,687 | 557,449 |

(단위: 비교 횟수)


## 4. 결과 분석

### 4-1. 데이터 크기가 커질 때 비교 횟수 변화

삽입 정렬은 n이 2배가 될 때마다 비교 횟수가 거의 4배씩 늘었다. 이건 삽입 정렬이 O(n²)이라는 이론과 맞는다.

쉘 정렬은 n이 2배가 될 때 비교 횟수가 약 2.2 ~ 2.4배만 늘었다. n이 1,000에서 20,000으로 20배 커졌을 때 삽입 정렬은 약 392배(≈ 20²) 늘었지만, 쉘 정렬은 약 40배만 늘었다. 그래서 n이 클수록 둘의 차이가 점점 더 커진다.

### 4-2. 삽입 정렬 vs 쉘 정렬

삽입 정렬 비교 횟수를 쉘 정렬(기본)으로 나눈 값은 다음과 같다.

| n | 삽입 / 쉘(기본) | 삽입 / 쉘(Knuth) |
|---:|---:|---:|
| 1,000 | 약 15.8배 | 약 18.5배 |
| 20,000 | 약 156.8배 | 약 180.5배 |

n = 20,000에서는 삽입 정렬이 약 1억 번 비교하는 동안 쉘 정렬은 60만 번 정도만 비교했다.


### 4-3. 쉘 정렬: 기본 간격 vs Knuth 간격

모든 n에서 **Knuth 간격이 기본 간격보다 비교 횟수가 적었다.**

| n | 기본 간격 | Knuth 간격 | Knuth가 줄인 비율 |
|---:|---:|---:|---:|
| 1,000 | 16,263 | 13,885 | 약 14.6% |
| 4,000 | 83,567 | 76,412 | 약 8.6% |
| 16,000 | 491,819 | 431,732 | 약 12.2% |
| 20,000 | 641,687 | 557,449 | 약 13.1% |

삽입 정렬과의 차이에 비하면 차이가 크지 않다.

간격을 쓰는 단계 수
- n = 1,000: 기본 간격은 500, 250, 125, 62, 31, 15, 7, 3, 1로 9단계, Knuth는 364, 121, 40, 13, 4, 1로 6단계
- n = 20,000: 기본 간격은 14단계, Knuth는 9,841부터 시작해서 9단계

Knuth는 단계 수가 더 적은데도 비교 횟수가 더 적었다.

## 5. 결론

- 삽입 정렬은 n이 2배일 때 비교 횟수가 약 4배로 늘어난다. (O(n²))
- 쉘 정렬은 n이 2배일 때 약 2.2 ~ 2.4배로 늘어나서, n이 커질수록 삽입 정렬보다 훨씬 유리하다. (n = 20,000에서 150배 이상 적게 비교)
- 쉘 정렬 중에서는 Knuth 간격이 기본 간격보다 약 9 ~ 15% 적게 비교했다.
- 간격 수열이 서로 겹치지 않고 적당한 속도로 줄어들수록 쉘 정렬이 효율적이다.
